# 破茧行情笔记(WEB版)

一款面向股票交易者的历史行情复盘与盘感训练工具。

官网：https://www.xkdwd.cn

---

## 是什么

破茧行情笔记用于帮助交易者通过回放历史行情、归档交易案例、比对情绪与热点，
建立属于自己的交易模式库和执行标准。

不是荐股软件，不提供买卖信号，不连接实盘账户。
核心定位是**交易内功训练**——让你反复看、反复拆、反复对齐自己的标准。

---

## 核心功能

- **历史行情回放**：支持 A 股/期货历史 K 线、分时走势回放，还原交易当时的完整盘面
- **交易案例归档**：将交割单按成功/失败/模糊分类，建立结构化模式库
- **情绪与热点比对**：叠加大盘情绪周期、板块轮动、涨停梯队进行复盘
- **盘感训练**：通过反复回看历史结构，训练"看到形态就认得"的本能反应
- **标注与检索**：支持给交易打标签、建分类，快速检索同类模式

---

## 适用场景

| 场景 | 说明 |
|------|------|
| 交割单复盘 | 逐笔反推决策逻辑，区分运气与能力 |
| 模式库建设 | 把反复验证有效的结构归档，形成自己的"武器库" |
| 盘感固化 | 大量回看历史走势，缩短"看到→认出→行动"的反应链 |
| 情绪周期学习 | 对照历史情绪拐点，理解市场节奏 |
| 交易纪律训练 | 用历史案例校准自己的执行标准 |
